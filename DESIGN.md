# General Game Design
Genre: Top-down 2D arena. A simple shooter where players move with WASD, aims with mouse, shoot projectiles, and try to be the last one alive.
Player count per match: 4-8.
Match length: 2-3 minutes max.
Win condition: Last player standing.
Map: Single fixed arena, ~1500x1500 units. No procedural generation. Maybe a few obstacles.
Player abilities: Move, shoot.
Visuals: Circles for players, lines for projectiles.
